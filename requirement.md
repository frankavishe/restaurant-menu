# Requirements

## Summary
I need a Django developer to build a simple, responsive restaurant menu website.

## Features
- Home page with restaurant info, logo, featured dishes, navbar and footer.
- Menu page showing food name, description, price, image and category.
- Category filtering and food details page.
- Django Admin to add, edit and delete categories and menu items.
- Contact page with restaurant information and contact form.
- Database models for Category, MenuItem and ContactMessage.
- Responsive design using Bootstrap.

## Tech Stack
Python, Django, HTML, CSS, Bootstrap, Django Templates, Django ORM and Django Admin.

No React, Vue, Angular, Django REST Framework or external APIs.

## Deliverables
Complete Django project, migrations, responsive UI, admin panel, clean code and setup instructions.
